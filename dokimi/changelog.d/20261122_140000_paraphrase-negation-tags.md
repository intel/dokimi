### Fixed

- **A faithful paraphrase that adds or drops a question tag or an opening contracted negative auxiliary is no longer dropped as `polarity_flipped`** — the novelty probes' paraphrase check strips an opening contracted negative auxiliary (`Doesn't`, `Isn't`, `Can't`, ...) and a trailing tag (`..., doesn't it?`) from a question before it compares negation presence, as the reversal check already did. A sentence that is not a question (`Don't install X as root.`) keeps its negation. A paraphrase that presumes the answer (`..., doesn't it?`) while its source does not is rejected as `leading_question`. A spelled-out `not` or a mid-clause `doesn't` still counts. `malformed_rate` of runs made before this change can be higher on the same skill, and a different set of paraphrases is kept.

### Added

- **`catalog routing` keeps one row per query for the lexical arm** — the result carries `lexical.per_query`, with or without `--reps`: `query`, `gold`, `rank` of the gold card and `picked`, as the single-artifact `per_query` plus the gold skill (`rank` is `null` and a `reason` replaces `picked` for a query with no content word), and `scores`, every card's BM25 score, which do not depend on the gold: `rescore_lexical_row(row, gold)` gives `rank` and `picked` for a corrected gold, ties included, and keeps a row with no content word unscored. A saved run can now be rescored after a gold label changes, split by query set half, or compared query by query with another run, without running it again. The model arm's rows stay in `model.noise.per_query`, which is also written with one repeat. The result file has no JSON Schema, so no schema version changes.

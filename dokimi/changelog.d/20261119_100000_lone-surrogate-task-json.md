### Fixed

- **A lone surrogate in a review comment or a task field no longer stops the replay and graph task writers** — a `\ud800` or `\udcff` escape in a gold comment or in a field of `task.json` raised `UnicodeEncodeError` when `eval tasks generate` wrote `gold.json` or `task.json` (the replay build, the replay authoring and the graph generators). The files are written with the lone surrogate replaced by `?`, so they stay valid UTF-8 and valid JSON; a high surrogate followed by a low one (the two code points a YAML double-quoted escape of one character loads as) is joined into its character first; the files of text that encodes as UTF-8 are unchanged byte for byte, with each line ending as the platform's text mode wrote it (`\r\n` on Windows).

### Fixed

- **`repo inspect` names instruction files and plugin manifests it cannot read, and refuses a directory it cannot list** — an `AGENTS.md` that is a link into an unsearchable directory, or any file in a directory without the search bit, ended in a `PermissionError` traceback (exit 5); a source directory of mode 000 was reported as an empty tree with `instructions.missing`. Such a root is now refused with exit 2 and its name. An instruction file that is a dangling or looping link, a link to a directory or device, a pipe or empty is still listed, but carries a `not loaded` note and a `not_observed` line, and a `.claude-plugin/plugin.json` or `marketplace.json` that is a directory is reported as a high-risk plugin that was not read, as a dangling link already was. `WorkTree.resolve` raises `SourceArgumentError` for an unreadable path and says `is not a regular file` for a pipe, not `links to nothing`.

### Fixed

- **A pinned source refuses a `--manifest` that leaves the tree** — `eval check`, `repo run` and `eval tasks generate --from replay|prs` on `<repo>@<sha>` with `--manifest ../outside.yaml` now exit 2 with `Error: path escapes the repository: ../outside.yaml`, as an unpinned directory does (on Windows, `..\outside.yaml` too); they reported a missing manifest and exited 1. A path that stays inside the tree, such as `a/../b`, is read as `b`; when `a` is a symlink, `..` goes up from the link's target, as in a checkout. A `..` after a directory the tree does not have, such as `nope/../x`, is no path: `is_file` and `is_dir` answer False, as they did before, and a read fails as a missing file.

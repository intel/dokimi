### Fixed

- **`repo reach` without `--salt` no longer stops for a checkout whose path has a non-UTF-8 byte** — the default salt is hashed from the label's UTF-8 bytes (`surrogateescape`, `key_bytes` in `utils.py`), so a surrogate-escaped directory name gets a salt instead of a `UnicodeEncodeError`; the salt of a UTF-8 label is unchanged.
- **A library id or query with a lone surrogate no longer stops the Context7 response cache or the topics cache** — `Context7Client.get_library_docs` and `RagasSeedExtractor.extract_topics` encode the key with `surrogatepass`, so a `local:` doc source whose directory name has a non-UTF-8 byte, or a question with a `\ud800` JSON escape, gets a key instead of a `UnicodeEncodeError`; the key of every library id and query that encodes as UTF-8, a NUL-led one included, is unchanged.
- **A question with a lone-surrogate escape no longer stops `compute_question_set_hash`** — a questions file with a `\ud800` or `\udcff` JSON escape loads as a lone surrogate, and the question-set hash encodes with `surrogatepass`, so such a set gets a hash instead of a `UnicodeEncodeError`; the hash of every set that encodes as UTF-8 is unchanged.
- **An atom statement or artifact text with a lone surrogate no longer stops the atom id or the retention cache key** — a statement parsed from a model reply or an atoms file can hold a `\ud800` escape; `Atom.__post_init__` and the retention `_key` encode with `surrogatepass`, so the id and the key get a digest, and those of every statement that encodes as UTF-8 are unchanged, which keeps the cached verdicts that are keyed on them.
- **A doc source with a JSON high surrogate no longer stops the URL cache key or the topics cache directory** — `URLClient._cache_key`, the question step of `EvaluationPipeline` and `questions generate`, and the same escape in a remote source URL (`cache_path`), a harness id (`_safe_id`) or a graph task's symbols (`task_id`) hash the source through `key_bytes`: a surrogate-escaped byte hashes as before, and a surrogate that `surrogateescape` cannot map (U+D800..U+DC7F and U+DD00..U+DFFF), such as a `\ud800` escape, tags the whole text `\0sp` and encodes it with `surrogatepass`, which differs from the escaped bytes of the same code point, and a text that starts with NUL gets `\0e` in front so that no text can look like the tag; both keys of a UTF-8 or non-UTF-8-byte source that does not start with NUL are unchanged; the directory name of a harness id with such a surrogate replaces it with `_` and adds the digest, so the directory can be created.

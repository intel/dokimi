### Fixed

- **Sign-flip p of a delta that dwarfs the others** — `sign_flip_p` added the signed deltas as floats, so from a delta of about 1e16 on the small ones were absorbed by the large one and all 64 sign patterns of `[1e17, 1, 1, 1, 1, 1]` summed to the same 1e17: its p was 1.0 and is now 0.03125, as for `1e15`. The sums are now exact (each delta an integer multiple of one power of two, so the p no longer depends on the order or the Python that adds them), for the exact enumeration and the Monte Carlo draws alike; the rounding slack that lets a pattern tie the observed sum (0.1 + 0.2 against 0.3) is unchanged. Rows of ordinary scale give the same p; the `1e9 + 1/3` row, whose sums only tie in exact arithmetic, is 0.0625 on every Python (0.046875 before on Python 3.11, which sums left to right). The interval search of a row of up to 16 changed deltas that span more than 40 binary orders of magnitude (`[1e17, 1, 1, 1, 1, 1]`) tests each shift with the same exact sums, so its lower end is 1.0, not the 0.0001 the float sums gave; a row of more than 16 such deltas is searched on exact sums too.

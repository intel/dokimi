### Added

- **`eval personas discover` can be priced and capped before it spends.** `--dry-run` reads the repo (or takes the description), prints the list-price estimate of its one generation call and exits 0: no model client is built and no personas or analysis file is written. `--max-usd X` makes the call only when that estimate is within `X`; above it, or for a model with no list price, no call is made and the command exits 3. Output paths are checked when writing files, after the estimate and budget gate. The estimate is not the bill: the real cost of the call can differ from it. The prompt is counted at four characters a token, which can run well low on ordinary text too, not only non-Latin text (a Bedrock-billed selection prompt had 1.55 times as many tokens as that count, issue #676), the reply is priced at a fixed 1500 tokens whatever `--count` is, and a retried request is billed again. `--save-analysis` now writes the analysis only when the call goes ahead, so a dry run or a refused cap writes nothing.

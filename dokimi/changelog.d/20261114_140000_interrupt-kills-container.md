### Fixed

- **Ctrl-C during `dokimi repo run` kills the cell's container by name** — before, only the docker CLI was stopped, so an agent or grader that ignores SIGTERM kept running (and spending) after dokimi exited. A timeout already did this. A batch's cells in worker threads (`--jobs`) are killed too: the batch stops the cells not yet started and kills each container still running, by name, until those cells return. A cell whose agent is killed is not recorded: it runs again on resume. A cell past its agent is graded and recorded before the batch stops: its grading container is not killed, so Ctrl-C waits for the grade.

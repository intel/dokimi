### Changed

- **Arms, harness and baseline flags: one spelling each.** `--arms` on `arms run`, `arms matrix-run` and `explore run` is now `--arm`, and it repeats: `--arm baseline --arm docs` gives the same list as `--arm baseline,docs`, which still works. `--harnesses` on `tasks run` is now `--harness`, repeatable the same way. `--baseline-json` on `arms plugin-delta` and `--base` on `docs compare` are now `--baseline`. The old spellings print the new command and exit 2, so scripts and CI that pass them must change the flag. `--arms` stays on `eval` and `skill novelty` commands, where it names a score or measurement arm, not a treatment. `--matrix-cells`, `--plugin-json` and `--work-harnesses` keep their names for now: each has no same-meaning canonical spelling yet.

### Fixed

- **`guidance_read` no longer lists a file a shell `head` or `tail` read with a count of zero** — `head -n 0 AGENTS.md` and `tail -c 0 AGENTS.md` exit 0 and print no line, but the walker took every file operand of `head` and `tail` as a read. A count that prints nothing (`-n 0`, `-c 0`, `-0`, `--lines=0`, `--bytes=0`, `head -n +0`, `tail -n -0`) is now no read; `head -n -0` and `tail -n +0` print every line and stay reads, and so does `tail -f -n 0`, which prints what is appended. A command prefixed with `POSIXLY_CORRECT=1` (or run through `env POSIXLY_CORRECT=1`) ends its options at the first file, so `POSIXLY_CORRECT=1 head AGENTS.md -n 0` prints the file and stays a read. (#1008)

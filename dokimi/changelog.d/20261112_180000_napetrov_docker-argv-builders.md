### Removed

- **Docker builder names moved** — `dokimi.repos.container.ContainerPolicy` is gone; import the policy and the limit from `dokimi.container_policy`. `dokimi.docker_cmd.PIDS_LIMIT` is now `dokimi.container_policy.PIDS_LIMIT`; `dokimi.docker_cmd.TASK_CONTAINER_HARDENING` and `dokimi.harnesses.container_agent.TASK_CONTAINER_HARDENING` are now `dokimi.container_policy.task_container_policy(network=, cpus=, memory=)`, which returns a `ContainerPolicy` rather than a flag list, so a caller that spliced the old flags builds its argv from that policy; `dokimi.harnesses.network_policy.start_args` is now `start_network`, which returns the network name rather than an argv list; `dokimi.harnesses.docker_solver.start_args` is now `start_network`; `dokimi.harnesses.docker_solver.TASK_CONTAINER_HARDENING` is likewise replaced by `task_container_policy`; `ContainerPolicy(memory_mb=…)` is now `ContainerPolicy(memory=…)`. `ContainerSandbox.run_args()` no longer returns `--network`; the task container takes it from its policy. The `docker run` argv the package builds is unchanged.

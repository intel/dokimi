### Changed

- **`skill novelty atoms`, `probe`, `analyze`, `skill routing` and `catalog routing` exit 3, not 1, when `--max-usd` or a call with no price stops them and they keep the partial file** — the exit-code table in `docs/quickstart.md` gives 3 to a run that stopped short on a budget and kept its partial output, as `tools preference` does, but these commands exited 1. The message on stderr is the same. A stop on a permanent provider error (`"reason": "permanent_error"`) is a runtime failure and still exits 1, as does a run that kept nothing (`skill shorten`) or an all-vs-all run where model calls failed. A script that read exit 1 as "stopped by the budget" now sees 3.

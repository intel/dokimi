### Fixed

- **L0 holds every submodule of a pinned snapshot as a directory, and a bad `.gitmodules` path no longer aborts the scan** — a gitlink (mode 160000) is a directory for L0 whether or not `.gitmodules` declares it, so a README that names `third_party/` keeps its `ok` verdict and a missing sibling file is `fail`, not `unresolved`. A `.gitmodules` path that leaves the tree (`../outside`) is ignored instead of raising `path escapes the repository`.

### Added

- **Next steps in `--json` documents**: `repo scan --json` and `repo inspect --json` now carry one `next` step when the run is complete: `repo budget <source>`, with `--cache-dir` when it was given. `runs list --json` carries `runs show <run_id>` for the newest run that has a `run_id`, unless the listing is `partial`. The `argv` of a step is the arguments after `dokimi`. Each step is free (`spends` false, `est_usd` 0, `kind` `sequence`). Every other `--json` command keeps an empty `next` by design. No schema change. (#941, #PR_NUMBER)

### Fixed

- **A disabled score gate is not recorded as passed** — `gate.soft.passed` in a run snapshot is `null` when the gate is disabled or missing from the spec, instead of `true`. An enabled gate is unchanged.
- **A trust verdict with no measured check reads `NOT MEASURED`** — when every check is unmeasured (no retrieval outcome, for example) the verdict is `⚪ NOT MEASURED`, not `✅ PASS`. A run with at least one measured check reads as before.

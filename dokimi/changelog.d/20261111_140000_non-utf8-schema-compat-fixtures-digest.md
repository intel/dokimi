### Fixed

- **A schema path or a fixture name that is not UTF-8 no longer stops the schema check or the fixture digest on Windows** — `python -m dokimi.schema_compat` read git's NUL-separated listing with `os.fsdecode`, which is strict UTF-8 on Windows and raised `UnicodeDecodeError`; it reads it as the other git readers do now (a byte that is not UTF-8 stays on POSIX and becomes U+FFFD on Windows), and reads each base schema by its git object id, as a name with U+FFFD in it names no path to `git show`; a base schema whose name is not UTF-8 reads with U+FFFD on Windows and cannot be matched to a work-tree file, so the check stops with exit 2 and names its bytes instead of letting a removal pass (other files that are not UTF-8 are ignored). `fixtures_digest`, the reach matrix's fixture digest, raised `UnicodeEncodeError` on a fixture whose name or link target is not UTF-8; it digests the name's bytes now. The digest of a UTF-8 tree is unchanged.

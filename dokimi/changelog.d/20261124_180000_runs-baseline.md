### Added

- **`runs baseline save|list|rm` names a run** — `runs baseline save NAME RUN` points a baseline at a run under the runs root, like a git tag, and `--expect-previous RUN_ID` makes the save a compare-and-swap: when the baseline no longer points to `RUN_ID` the save exits 4 and leaves the pointer as it was, so two nightlies cannot overwrite each other. Names can carry a namespace (`skill/a@main`); `runs baseline list` prints each with its run, `runs baseline rm` removes the pointer and keeps the run, and `--json` prints `cli_output.v1`. `runs gc --keep-baselines` now also keeps the runs these baselines point to (#94 R3).

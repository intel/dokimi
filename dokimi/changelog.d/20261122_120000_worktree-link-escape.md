### Fixed

- **A manifest link that leaves the repository and comes back in is refused alike from a directory and from `<dir>@HEAD`.** A committed link such as `.agent-eval/rt.yaml -> ../../repo/real.yaml` was read from the directory (it resolves inside it) and refused from `<dir>@HEAD` with `path escapes the repository`. The directory now refuses it too: a link whose `..` goes above the root escapes, whatever it resolves to. An absolute link into the directory is still followed from the directory. On Windows, a path or link text with another drive (`Q:x`) or a leading `\`, and a junction out of the directory, are refused too, on Python 3.11 as well; and a `..` after a missing name or a file is `no such path` from a directory, as from `<dir>@HEAD`.

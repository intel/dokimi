### Fixed

- **`skill shorten` and `skill novelty analyze` refuse a `--cache-dir` they cannot store into, before any paid call** — a `--cache-dir` naming a regular file (or whose parent is one, a dangling symlink, a path below a directory without search permission, or a missing directory below one that is not writable) ended both commands in a traceback on the first retention adjudication (`FileExistsError` for a regular file, another `OSError` for the rest). They now exit 2 with `--cache-dir <path> is not a directory` (or names the directory that is not readable or writable). A directory that exists, read-only or not, and one that does not exist yet below a writable directory are taken as before: a read-only cache still replays the verdicts it holds, and a verdict it cannot store is decided again on the next run instead of ending the command.

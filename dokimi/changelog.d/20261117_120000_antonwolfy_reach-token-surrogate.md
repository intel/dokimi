### Fixed

- **A file path with a lone high surrogate no longer stops the reach token** — `token` in `repos/reach.py` hashes `key_bytes` of its text, so a path such as `"n\ud800"` (a `\ud800` escape in JSON) gets a token of its own instead of a `UnicodeEncodeError`; the token of every path that encoded before is unchanged. `Bundle.measured_digest` in `novelty/bundle.py` hashes its path rows the same way. A profile `guidance.shadow_file` with a lone surrogate, which the shadow file's UTF-8 write cannot take, is refused by `shadow_for` with a `ReachError` before the first harness call, on a dry run too.

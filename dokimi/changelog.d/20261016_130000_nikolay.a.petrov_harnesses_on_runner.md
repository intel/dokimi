### Changed

- **`command:`, Harbor, BenchFlow and explorer processes are contained** —
  these now start through the process runner, so a timeout kills the whole process
  tree (an agent's tool calls, `harbor`'s children), not only the command, and
  anything the command leaves running when it exits is killed too. The command's
  stdin is closed, and its output is read as UTF-8 whatever the locale. A timed-out
  `bench` gets SIGTERM and 15 s to stop before SIGKILL, also on Ctrl-C (where
  `bench` used to be left running); a second Ctrl-C does not restart that grace.
- **`repo run` stops its container gently and bounds docker calls** — a timed-out
  `docker run` CLI gets SIGTERM and 10 s before SIGKILL, then `docker kill` stops
  the container by name once the CLI is gone; `docker build` fails after 3 h and
  `docker image inspect` after 60 s instead of hanging the batch.
- **Library API** — `repos.container.kill_group` is removed (the runner kills the
  group), `run_process` takes a `runner` argument, and
  `BenchflowHarness.preflight()` is an instance method. `bench.log` keeps the first and last 512 KiB of each of `bench`'s
  streams. A wrapper that relied on a background process outliving its cell must
  now wait for it.

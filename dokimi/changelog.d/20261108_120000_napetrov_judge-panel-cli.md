### Added

- **Judge panel for skill novelty**: `skill novelty analyze` and `probe` now take `--judge PROVIDER/MODEL`. Repeat the flag to form a panel. `--judge-aggregate {median,majority,unanimous}` (default `median`) turns the panel's verdicts into one per answer. The record gets a `judge_panel` block: each judge's own paired 2×2, the judge range of the added share, and a `judge_sensitive` flag set when that range exceeds 0.10. Each run keeps every judge's verdict (`analyze` writes them to `<record>.judge_verdicts.json`), and the report names the panel. A warning is printed when two judges share a vendor family. The `--estimate-only` dollar figure and call counts include the extra judges. A model given twice, under any spelling, is refused. Background: `docs/judge-panel-study.md`.

### Added

- **`runs rm` and `runs gc` remove runs from the runs root** — `runs rm RUN_ID` removes the artifacts that carry the `run_id`, `runs rm PATH` one file under the root, and `runs gc --older-than 30d` every run whose newest artifact is older than that; `--keep-baselines` keeps the runs a `baseline save` copy holds, `--dry-run` lists without removing, and `--json` prints `cli_output.v1`. Files that are not artifacts, artifacts with no `run_id` (for `gc`), directories and anything outside the root stay. A file that cannot be removed exits 5 (#94 R3).

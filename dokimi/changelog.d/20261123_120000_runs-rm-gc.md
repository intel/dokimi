### Added

- **`runs rm` and `runs gc` remove runs from the runs root** — `runs rm RUN_ID` removes the artifacts that carry the `run_id`, `runs rm PATH` the one file named under the root, artifact or not, and `runs gc --older-than 30d` every run whose newest artifact is older than that; `--keep-baselines` keeps the runs a `baseline save` copy holds, `--dry-run` lists without removing, and `--json` prints `cli_output.v1`. Removing a run leaves files that are not artifacts and directories in place, `gc` never removes an artifact with no `run_id`, and nothing outside the root is touched. A file that cannot be removed exits 5 (#94 R3).

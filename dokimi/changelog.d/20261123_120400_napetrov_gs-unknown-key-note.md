### Changed

- **`frontmatter-unknown-key` is a `note`, not a `warn`** — a frontmatter key that neither the Agent Skills spec nor Claude Code names (`tags`, `author`, `category`, ...) may be a field a harness reads, so it is information, not a defect. A `note` never changes the skill's state, so a skill whose only finding is such a key now reads `ok` where it read `warn`; `--strict` never failed on it (it fails on a spec error, not a warn). The default text output still prints the note under the skill's row, so it is shown, not hidden. The catalog's `warn` count drops by those skills. `--fail-on-code frontmatter-unknown-key` still exits 1 on it. The code, its message and the other checks are unchanged. (`info` is not a level here: `error`, `warn` and `note` are.)

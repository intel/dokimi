### Fixed

- **`eval check` and `repo run` refuse a `--cache-root` or a `--cache NAME=PATH` that is not a usable directory with exit 2 naming the flag and the path** — a regular file, a path below one, or a `--cache-root` holding a regular file named after a cache used to end in `✗ [Errno 17] File exists` or in `✗ [Errno 20] Not a directory`, and exit 1 after the image build; the paths are now checked before the export and the build. A path that cannot be resolved (a symbolic link loop) is refused the same way, and a `--cache-root` that is a regular file is refused also when every cache has its own `--cache` and when the manifest declares no cache. An existing read-only directory still passes as a build cache.

### Fixed

- **`dokimi arms run` and `arms matrix-run` keep the answers paid for when the process dies mid-run** — the arms output used to be written once, at the end, so a crash, SIGKILL or the OOM killer lost every answer. The run now rewrites `<out stem>.partial.json` beside `--out` (a cell's `cells/<cell>.partial.json`) after each answered question: an `arms.v1` file with a `partial` block (`questions_requested`, `questions_recorded`), the answers so far and no scores, removed once the whole run is saved. It never replaces a finished file, and `eval headroom`, `arms plugin-delta` and the other commands that read arms files refuse it. A run that fails with a message names the file. An `--out` that cannot be written now stops the run with exit 2 after its first question at the latest, not after the last one. (#228)

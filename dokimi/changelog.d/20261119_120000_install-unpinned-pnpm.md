### Fixed

- **`catalog check` now counts unpinned `pnpm add`, `pnpm install` and `pnpm i` packages in `install-unpinned`, counts each package once, and skips echoed text** — only `pip`, `npm` and `npx` were read, so a skill that ran `pnpm add -D parcel html-inline` got no finding where the same line with `npm install -D` got one for two names. The finding now names `pnpm`, with `--filter`, `-F`, `--dir`, `-C`, `--store-dir`, `--save-catalog-name`, `--reporter`, `--modules-dir`, `--virtual-store-dir`, `--lockfile-dir` and `--global-dir` values left out. `pnpm dlx` and `pnpx` are read as `npx` is, with a `--package` selection before `dlx` judged as one after it. The count is now of distinct `<manager> <name>` pairs, so `pip install anthropic` shown in three places is one install, and a command inside the quoted text of an `echo` or `printf` is not an install, unless a substitution in it runs the command or the output is piped to a shell, also across a newline. A `#` comment is skipped before its quotes are read. (#946)

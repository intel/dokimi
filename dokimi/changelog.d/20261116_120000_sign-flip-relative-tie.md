### Fixed

- **The sign-flip test no longer reads deltas that vary at a tiny scale as ties** — deltas such as `[1e-300, 3e-300, 2e-300, ...]` were all within the absolute 1e-9 tie width, so `paired_test` and `repo compare` gave them `n_changed` 0 and no `p` next to a `large` effect size. A tie is now within 1e-9 of 0 as before, but within 1e-9 times the largest delta when that is below 1e-9, so such a vector gets a `p`, an interval and the same verdict as its 1e-3 scale copy. A vector whose largest delta is 1e-9 or more keeps the 1e-9 tolerance, and every result for it is unchanged; an all-zero vector still has no `p`. `repo compare` counts `up`, `down`, `tied` and `mde` with the same width, and the non-inferiority check of `paired_cluster_difference` scales its slack the same way.

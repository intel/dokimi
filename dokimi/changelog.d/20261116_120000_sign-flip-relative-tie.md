### Fixed

- **The sign-flip test no longer reads deltas between values of a tiny scale as ties** — `paired_test([2e-300, 4e-300, ...], [1e-300] * 8)` had `n_changed` 0 and no `p` next to a `large` effect size, because every delta was within the absolute 1e-9 tie width. A pair whose larger value is below 1 now ties within 1e-9 times that value (1e-9 for values of 1 or more, as before), since float noise in `t - b` scales with the values and not with the delta: that vector gets a `p`, an interval and the verdict of its 1e-3 scale copy, and `0.1 + 0.2` against `0.3` stays a tie. Each pair keeps its own width whatever the other deltas are. `paired_test` and `repo compare` (`n_changed`, `up`, `down`, `tied`, `mde`) use it; a caller that passes deltas alone keeps the absolute 1e-9. An interval of deltas near the smallest floats excludes 0 with its `p`, where it was `[0, 0]`.

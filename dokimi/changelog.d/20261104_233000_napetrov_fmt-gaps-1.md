### Added

- **Task import reads four more formats** — `dokimi eval import` now judges a custom Inspect `@scorer` on its docstring (a bare one stays unsupported), loads `hf_dataset(...)` rows through the `datasets` package (a builder such as `json` reads `data_files=` from the task's directory; a local dataset folder or file is refused; `trust_remote_code=` is refused), reads a promptfoo config written as code (`promptfooconfig.js`/`.mjs`/`.cjs`/`.ts`, which needs `node` on PATH), and grades a model-graded OpenAI spec with no ideal by its registry prompt. A Harbor `evaluation/harbor/suites.json` is detected as `harbor-suites` and its tasks are counted by `dokimi eval inspect`.

### Fixed

- **A skill directory with a file whose name is not UTF-8 is digested, not a traceback** — on POSIX `repo run` with a skill arm, and the batch ledger and guidance arms that digest a tree, raised `UnicodeEncodeError` on such a file name while hashing the skill. The digest now takes the name's bytes (`os.fsencode`); the digest of a tree of UTF-8 names is unchanged.

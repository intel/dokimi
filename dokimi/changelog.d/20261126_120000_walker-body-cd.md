### Fixed

- **A `cd` after the first command of an `if` or loop body no longer moves the repo walker's directory** — `if false; then :; cd sub; fi; cat f` listed `sub/f` as read, though bash skips the body and reads `f` in the start directory. A `cd` in an open `then`, `else`, `elif` or `do` body now loses the directory, as a `cd` right after the keyword already did, so the later `cat f` is no read; so does a `cd` in the condition of an `if` nested in such a body (`if true; then if x; cd sub; then :; fi; fi; cat f`). The exception is a body that opens with a `case`: `if x; then case a in a) :;; esac; cd sub; fi; cat f` still reads `sub/f`. A `cd` in a condition outside any open body, or after `fi` or `done`, is unchanged.

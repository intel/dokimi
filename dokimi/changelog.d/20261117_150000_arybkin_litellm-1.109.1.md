### Fixed

- **`skill-agent:` arms answer again from a locked install** — litellm 1.106.0 to 1.108.3 import `mcp`, which Dokimi does not install, on every `completion(tools=...)` call, so each agent arm answer was recorded as `agent_failed: No module named 'mcp'` while `arms run` still reported `OK`. Dokimi now requires `litellm>=1.108.4`, and `requirements.lock.txt` and the Intel CI conda locks pin litellm 1.109.1. If you installed Dokimi with `pip install dokimi` and an older litellm, run `pip install -U "litellm>=1.108.4"` and re-run affected `arms run` batches.

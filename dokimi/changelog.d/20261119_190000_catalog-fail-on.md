### Added

- **`catalog check --fail-on CODE`** — repeatable; the scan exits 1 when a finding with that code is left after `--ignore`, at any level, so an edit loop or a gate can fail on a `warn` or `note` such as `description-no-when` or `link-missing`. An unknown code is a usage error, as with `--ignore`. `--strict` is unchanged. With `--json` the skill's subject has verdict `fail`; with `--per-skill --resume` the current selection applies to the rows kept.

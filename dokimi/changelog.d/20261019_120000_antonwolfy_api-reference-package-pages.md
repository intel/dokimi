### Documentation

- **The API reference's package pages have content** — `dokimi`, `dokimi.ingest`, `dokimi.metrics` and `dokimi.runner` had no module docstring. On the site, the `dokimi.metrics` page listed its usage record with no word on what the package is, and the other three showed only a heading. Each now says what the package does, and the `dokimi` page, the API reference's landing page, maps every subpackage to its evaluation track with a link to its page.

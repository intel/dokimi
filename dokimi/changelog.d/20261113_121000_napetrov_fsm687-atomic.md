### Fixed

- **A failed write no longer leaves a half-written or stray file** — the pin, ledger, lock, atoms, probe and response-cache writers, and the task writers' `task.json`, `gold.json` and `change.patch`, now publish through one helper: a pid- and thread-unique tmp file, then `os.replace`. A failed write keeps the file that was there and removes its tmp file. A write replaces what is at the target path rather than writing through it: a symlink there becomes a regular file (its target is left as it was), and a read-only file is replaced too, keeping its mode, so it stays read-only. A file owned by another user (for example one written as root under sudo) is replaced by one owned by the user who runs the write.

### Fixed

- **The novelty faithfulness check no longer reads a list item or a "this" sentence without the text it points at** — `verify_atoms` judged an atom against its cited spans alone, so `- Large arrays (>10,000 elements)` lost its lead-in `Use dpnp for:` and `Prefer this over plain NumPy` lost the sentence naming the subject, and supported atoms read as unsupported. The prompt now also carries a CONTEXT block, the heading path of the first cited span and its lead-in (the nearest earlier span that is not a list item or table row, or the span just before a sentence; never a heading or a span of another section), plus the header row of a cited table row, only to resolve references: the verdict is still about the cited spans, and a changed polarity or number stays `distorted` or `unsupported`. Cached faithfulness verdicts for the old prompt are asked again, and faithfulness counts from runs before this change are not comparable with new ones. (#1009)

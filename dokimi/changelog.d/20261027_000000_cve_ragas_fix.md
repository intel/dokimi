### Fixed

- **RAGAS dependency**: removed from main `requirements.txt` to fix recurring CVE
  reports. ragas is already optional in `pyproject.toml` as the `[ragas]` extra.
  `pip install dokimi` no longer installs ragas, langchain-community,
  langchain-anthropic, langchain-openai, or langchain-core. Commands that
  require the `[ragas]` extra (`eval ragas`, `answers generate --ragas`) now
  check for the extra at entry and exit with a helpful install message before
  any model call. This fixes CVE-2026-2447 (diskcache) and CVE-2026-3046 (ragas).
  The optional filelock CVEs (GHSA-v4x8-3wr5-3wq8, GHSA-9vhv-jxww-xfm5,
  GHSA-567q-5qvw-pf92) remain because litellm requires `filelock<4.0`.

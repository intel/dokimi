### Fixed

- **`run`, `compare`, `arms`, `tasks`, `explore` and `repo`** exit with a message on the unreadable, non-UTF-8 or corrupt spec, snapshot, result, plan, task and question files their tests cover, or an unwritable output, instead of a traceback. Some other readers still raise, for example `repo scan --manifest-file`, `repo scan --static`, `repo reach` and `repo budget --harness`, `arms run --questions` and `tasks run --tasks`. `run` and `compare` exit 2 on a bad spec or snapshot (a non-numeric summary value, or fewer documents than the manifest's `min_docs`) and exit 1 when an output cannot be written, as `arms` does. `repo report` and `repo compare` exit 1 on a result file without a usable `grade`, `agent`, `task`, `arm` or `model`. `tasks` error messages use the `Error:` prefix.

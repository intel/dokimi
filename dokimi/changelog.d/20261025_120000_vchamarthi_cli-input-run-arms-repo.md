### Fixed

- **`run`, `compare`, `arms`, `tasks`, `explore` and `repo`** exit with a message on the unreadable, non-UTF-8 or corrupt spec, snapshot, result, plan, task and question files their tests cover, or an unwritable output, instead of a traceback. This covers a deeply nested `--manifest-file`, `--static` or `--harness` file, a non-UTF-8 `.agent-eval/repo-eval.yaml`, and a `tasks run --tasks` name that is missing or unreadable. `run` and `compare` exit 2 on a bad spec or snapshot (a non-numeric summary value, or fewer documents than the manifest's `min_docs`) and exit 1 when an output cannot be written, as `arms` does. `repo report` and `repo compare` exit 1 on a result file without a usable `grade`, `agent`, `task`, `arm` or `model`. `tasks` error messages use the `Error:` prefix. `repo run` records `agent.num_turns` as null when the harness reports anything but an integer, so the batch stays reportable; a finished run with such a value still counts as started.

### Added

- **Repository budget command** — `dokimi repo budget <source>` lists what the tree puts into an agent's context when the agent starts at the repository root, and when each part loads. The command reads only the tree and calls no model, sizing guidance files and skill listings and bodies, and listing `.mcp.json` server names (not sized). Output distinguishes four load times: `start` (root CLAUDE.md files, a root AGENTS.md when no root CLAUDE.md displaces it, and the `@` imports of root CLAUDE.md files), `lazy` (nested guidance), `on demand` (skill bodies), and `off` (guidance never loaded). Supports `--json` for structured output, `--harness` to pick the profile whose guidance file names are read, and `--fail-on-warning` to exit 1 on any warning: skills with no description, near-duplicate skill descriptions, `AGENTS.md` files turned off by a root `CLAUDE.md`, and unreadable files.

### Added

- **`skill novelty analyze` saves each atom's judged and measured verdicts beside the artifact, and `skill novelty view --atom-verdicts FILE` colours spans from them** — `analyze` now writes `<out stem>.atom_verdicts.json` (`novelty.atom_verdicts.json` beside `novelty.json`), a new `novelty_atoms` artifact (`novelty_atoms.v1`), and `<out stem>.atoms.json` (`novelty.atoms.json`), the atoms and spans the run extracted in the format of `skill novelty atoms`' `atoms.json`; it prints `OK Saved atom verdicts:` and `OK Saved atoms:`. The verdicts file has one row per atom the run probed (a capped run's sample) with `id`, `statement`, `question`, `answer`, `kind`, `tags`, `span_ids`, `faithfulness`, the judged `needed`, `scaffolding`, `conflict` and `conflict_why`, the measured paired `outcome` under `lenient` and `strict` scoring, and the content `category`, plus the run's `with_arm`, `ref_digest` (the artifact revision), `analysis_digest` (a `sha256:` digest of the `novelty.json` payload without `schema_version`, `run_id` and `dokimi_version`) and its `conflicts` pairs. The judged fields and `category` are `null` for a run with `--no-classify` or a tier without classification, `needed` and `scaffolding` are also `null` for an atom the value judge gave no answer even when a conflict names it, `conflict` and `conflict_why` are `null` for an atom the conflict check never compared with anything, the `category` uses the lenient outcome, and `outcome` is `null` for an atom with no usable pair. A file left by an earlier run into the same output is overwritten. `novelty.json`, `novelty.md` and the annotated view are unchanged. `view --atom-verdicts` re-renders the annotated view with outcome and category colours with no model call, and exits 2 for a file written beside another analysis (a different `artifact_ref`, `ref_digest`, `model`, `run_id` or `analysis_digest`, a missing `run_id` included; two analyses that share a `DOKIMI_RUN_ID` differ in their `analysis_digest`) or naming atoms the `--atoms` file does not hold or cites other spans for (an `--atoms` file extracted again from an edited source keeps the ids and moves the spans), or for an `--atoms` file whose `bundle.measured_digest` differs from the `--novelty` artifact's `ref_digest` (an atoms file without that digest is not checked against it) (pass the run's `novelty.atoms.json`); without the flag `view` colours by span structure and category as before.

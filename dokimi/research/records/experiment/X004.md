## Setup
81 paired questions, hosted judge, skill answers re-judged with and without the skill manifest in context.

## Result
Without context skill lost 29/81 (judge called existing skill file paths 'fabricated', 17/81 flagged). With context 60/81. Symmetric control: baseline alone gained ~+4 from context; 36/81, p=0.087.

- local run, n=81 paired

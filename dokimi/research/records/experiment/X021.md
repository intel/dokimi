## Setup
421 runs, Haiku 4.5 / Sonnet 5.5, n=3-5 per cell (directional).

## Result
Stale facts adopted near-totally; 'verify' prompt helped only Sonnet (4/5); 150k irrelevant history kept accuracy but cost 16-31x; guidance file beat code and skill on clash 10/10; prune ~10-20x cheaper than compaction at equal accuracy. Follow-up on compaction: it dropped ~7% of tokens (107,547 -> 99,842) with 5/6 accuracy (Haiku miscounted once); pruning reads peaked at 9.6k/5.8k tokens with 6/6.
